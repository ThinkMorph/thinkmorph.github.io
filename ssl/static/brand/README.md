# ThinkMorph-SSL logo

The tail of the teal ThinkMorph arrow breaks into a mosaic and turns solid toward the tip: from a corrupted to a restored image. It belongs to the ThinkMorph family: the same circle with the head and the morph arrow, the same teal and indigo, and the same wordmark; each member changes one small thing.

| File | Use |
| --- | --- |
| `thinkmorph-ssl-mark.svg` | the mark, vector; favicons and anywhere it can scale |
| `thinkmorph-ssl-mark-512.png`, `-192.png`, `-32.png` | the mark as PNG with a transparent background |
| `thinkmorph-ssl-logo.png` | mark and wordmark on light backgrounds (README, slides, cards) |
| `thinkmorph-ssl-logo-on-dark.png` | mark and wordmark on dark backgrounds |

Colours

| Name | Hex | Where |
| --- | --- | --- |
| Teal | `#13898A` | the arrow (ThinkMorph teal, close to the paper's AdviseTeal) |
| Indigo | `#4E4596` | the crescent around the head |
| Periwinkle | `#6169B3` | the wordmark "ThinkMorph" |
| Suffix | `#13898A` | "-SSL" |

Wordmark: Carlito Bold (a metric twin of Calibri, Google Fonts), as in the ThinkMorph wordmark.
