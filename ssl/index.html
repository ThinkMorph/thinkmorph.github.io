    01

    Reasoning with images needs examples of it.
    Images themselves can supply some.

    In interleaved reasoning, language guides image generation, and the resulting images inform further reasoning. Unified models support this natively. Training it, however, usually relies on traces built for specific questions, whose visual targets and construction pipelines must be designed for each task family.

    Classical self-supervised learning faced the same supply problem and solved it with pretext tasks: corrupt an image, then predict the original. The target comes from the image, so supervision grows with the image pool. ThinkMorph-SSL turns these tasks into interleaved reasoning traces and uses them as a first training stage, before task-specific instruction tuning.

    Read the abstract

    Interleaved multimodal reasoning allows models to generate intermediate images and use them in subsequent reasoning. Training this ability, however, usually relies on question-specific traces whose visual targets and construction pipelines must be designed for each task family. This dependence limits the supply of supervision even when source images are abundant. We introduce ThinkMorph-SSL, a two-stage recipe that expands this supply through self-supervised learning (SSL) on classical visual pretext tasks. The first stage, pretext reasoning, turns corrupted–clean image pairs into interleaved traces that describe the input, restore the image, and describe the result. The original image supplies the visual target, and a multimodal teacher synthesizes the text, allowing the same construction pipeline to serve different image collections without task questions. Instruction tuning then connects this practice to question-driven reasoning. Experiments show that pretext training improves subsequent learning and that using it before instruction tuning is more effective than mixing the two sources. The resulting model improves perception, spatial understanding, and mental world modeling over its base model with text reasoning. These findings support scaling interleaved supervision by drawing on images themselves alongside task-specific demonstrations.

    The base model cannot do this yet

    We first let BAGEL-7B reason without any training. Longer text reasoning lowers its mental-world-modeling average. Inserting an intermediate image into its reasoning, even a correct ground-truth one, also lowers accuracy. Reasoning with images has to be learned.

    02

    Two stages, one trace format.
    First the mechanics, then the use.

    Stage 1 · Pretext reasoning

    Restore it, and say what changed

    Corrupted–clean pairs become instruction-free traces. The model sees only the corrupted image, describes the visible evidence, generates the restored image, and describes the restored scene. The trace never names the corruption, so the model must infer it.

    pθ(T0, I0, T1 | Ic) = pθ(T0 | Ic) · pθ(I0 | Ic, T0) · pθ(T1 | Ic, T0, I0)

    Stage 2 · Instruction tuning

    Build the image the question needs

    The same interface, now with a question. Each trace contains reasoning text, one or more intermediate images chosen because they help answer, and a final answer. It teaches when to construct a visual state, which state to construct, and how to read the answer from it.

    (ximg, xtext) → T0 → I0 → ⋯ → TK

    Two corpora, same interface.
    One grows with images, one with pipelines.

    Stage 1

    Pretext-270K

    270,896 traces

    Instruction-free Thought–Image–Thought traces, balanced across seven programmatic transformations. The original image supplies the visual target; GPT-5 writes the two thoughts from both images and a reference caption.

    Transformations
    Jigsaw · colorization · super-resolution · masked inpainting · rotation & flip recovery · denoising · deformation recovery
    Image sources
    SA-1B · PixMo-Cap · VSI-590K · LLaVA-OneVision-1.5 · DeepVision-103K · Matterport3D · Realsee3D · 360+x
    Questions needed
    None. New image pools can be added as is.

    Stage 2

    Instruct-181K

    181,291 traces

    Question-driven interleaved traces from nine construction pipelines. Wherever possible, answers come from geometry, annotations, or metadata rather than from a language model.

    04

    Reasoning with images beats the same model reasoning in text,
    on all twelve benchmarks.

    We train BAGEL-7B-MoT with both stages and compare it with the same backbone reasoning in text (think-4k), across twelve benchmarks in three levels. It improves every benchmark, including the nine that share no source dataset or task family with Instruct-181K. A 16K text budget moves the three level averages by at most 2.46 points.

    Δ is computed against BAGEL think-4k. HR-4K / HR-8K are HRBench at 4K / 8K; MME-RW-L averages its reasoning and perception sub-scores. All models run through the same adapted VLMEvalKit pipeline.

    Where it stands

    On the L2 and L3 averages it exceeds every open-source baseline except the concurrent SenseNova-U1-8B, whose architecture, data, and training scale differ. It leads Qwen2.5-VL-32B by 5.48 and 5.17 points, and its L3 average is slightly above Gemini 2.5 Flash (41.10 vs. 40.35).

    Where it doesn't

    GPT-5 leads on all three averages. On L1, Qwen2.5-VL-32B and LongCat-Next-A3B score higher. The model still trails BAGEL's own direct answers on BLINK, OmniSpatial, SpatialViz, and RealWorldQA; on each of these, text reasoning also hurts the base model.

    05

    Does the pretext stage matter?
    Held fixed, one variable at a time.

    Does the model use the images it generates?

    The base model gained nothing from a correct intermediate image. After training, the image matters. We sample eight trajectories per problem and let the model decide whether to generate an image. These are within-problem associations, not interventions.

    What does it cost?

    Generating an image costs far more FLOPs than writing text (5.73P vs. 0.08P per V⋆ question for think-16k), but image denoising runs at about 62% hardware utilization while autoregressive text decoding stays below 1.1%. The written reasoning is also much shorter.
