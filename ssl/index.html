    Introduction

    Models that reason with intermediate images are usually trained on traces built for one task family at a time. Self-supervised pretext tasks need no such traces, because the original image is the answer. ThinkMorph-SSL turns these tasks into interleaved reasoning traces and trains on them before instruction tuning. Compared with the same model reasoning in text, it gains 9.84 points on perception, 4.22 on static spatial understanding and 17.92 on mental world modeling.

    The base model cannot do this yet

    Without training, more text reasoning lowers BAGEL's L3 average. Forcing an image step lowers accuracy, even when the image is the ground truth.

    Method

    Both stages use the same interleaved trace format. Stage 1 trains on pretext traces, which have no question. Stage 2 trains on question-driven traces, and the model draws the images that help answer the question.

    Data

    Pretext-270K holds 270,896 traces. Each one restores an image after one of seven programmatic corruptions, and the images come from eight public datasets. Instruct-180K holds 180,490 question-driven traces from nine construction pipelines at three levels.

    Results

    Trained with both stages, BAGEL-7B-MoT beats the same model reasoning in text (think-4k) on all twelve benchmarks, by 11.33 points on average.

    Analysis

    With the same Stage-2 budget, pretext reasoning adds 6.28 points on V⋆, 7.33 on SAT and 5.85 on SpatialViz. On MindCube, the staged run ends 4.9 points higher on BAGEL-7B and 4.72 points higher on InternVL-U-4B.

    Pretext training before instruction tuning reaches 66.6% on MindCube, while mixing both corpora stays near 57%. Instruction-free pretext traces lead instructed ones by 2.7 points on average.

    We sample eight traces for each of 150 problems per split, and the model decides whether to draw an image. Traces with an image are more accurate, and images with critical defects come with more errors.
